# Manuscript

`manuscript.tex` is the English source for the revised research manuscript.
`manuscript.pdf` is the checked PDF distributed with this repository.

Compile from this directory with a TeX distribution that provides `IEEEtran`:

```text
pdflatex manuscript.tex
pdflatex manuscript.tex
```

The source references the versioned figures in `../figures/publication/` and
contains no individual email addresses. The manuscript reports a
methodological audit and must not be interpreted as a clinical validation.

# Security policy

## Supported version

Security and reproducibility fixes are made against the current `main` branch.

## Reporting a vulnerability

Do not include private data, credentials, or exploit details in a public issue.
Use GitHub's private vulnerability-reporting feature for this repository with a
concise description, affected file or command, and safe reproduction steps.

## Clinical safety

This repository is research code only. It must not be connected to a clinical
decision workflow or used to guide diagnosis, treatment, triage, or emergency
action.
